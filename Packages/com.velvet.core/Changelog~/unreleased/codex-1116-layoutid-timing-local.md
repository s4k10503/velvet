### Fixed
- Restore the element's inline transition duration, delay, and easing after a Motion tween completes or is interrupted. If tween plays overlap on one element, each slot keeps the value of the latest one still playing that wrote it, and the last to end restores the element's own timing. Preserve code changes whose keyword or list entries differ from the value Velvet last wrote when it next writes or releases a tween's timing, without a playing tween putting its value for that slot back; identical reassignments and changes undone before observation do not replace the saved timing.
